# lectra-ai
Multilingual AI lecture learning assistant

## Запуск

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для создания учебных материалов добавьте `GEMINI_API_KEY` в
`.streamlit/secrets.toml` или в Streamlit Cloud → Settings → Secrets.
Не добавляйте этот файл в репозиторий. Запись, локальное прослушивание и
скачивание работают без ключа. После остановки записи нажмите
«Создать материалы», чтобы отправить аудио на сервер и в Gemini.

## Аудио

- «Выбрать аудиофайл» поддерживает MP3, M4A, WAV, AAC, OGG/OGA/OPUS,
  FLAC и WebM/WEBA. Принимается также MP4 с аудиодорожкой.
- Если системное меню скрывает запись, используйте «Не видно аудио?
  Открыть все файлы». На телефоне выберите «Файлы»/«Обзор»; запись диктофона
  может потребоваться сначала сохранить туда. Названия пунктов определяет ОС.
- «Скачать аудио» сохраняет исходные байты и фактическое расширение, независимо
  от успеха AI. «Сохранить / поделиться» появляется при поддержке браузером.
- Ограничения: 450 МиБ и четыре часа. Формат, который браузер не воспроизводит,
  всё ещё можно скачать или проверить серверным декодером.
- Заметки и аудио хранятся локально в IndexedDB. Очистка данных браузера удаляет
  их; делайте резервные копии. Во время записи не закрывайте вкладку: фоновая
  запись и восстановление после аварии не гарантируются мобильными браузерами.

Передача и AI — разные этапы. Аудио отправляется подтверждаемыми частями по
4 МиБ через компонент Streamlit, с ограниченным повтором при потере ответа.
Прогресс показывает подтверждённые сервером байты. Можно отменить передачу и
продолжить её кнопкой «Создать материалы» в той же серверной сессии.
После обновления страницы или перезапуска сервера отправка может начаться заново.
Сервер хранит до двух временных записей общей величиной до 450 МиБ; старые
загрузки вытесняются. Копии для декодирования хранятся отдельно во временной
папке сессии и очищаются вместе с ней.

Декодер отдаёт первые пять минут до декодирования всей лекции. Готовые WAV-части
кешируются, а успешные ответы AI используются повторно при продолжении текущего
задания. Готовый результат последнего задания также используется повторно.
Время распознавания зависит от Gemini, квоты, длины записи и сети; быстрый
локальный импорт не означает мгновенную транскрипцию.

## Проверки

```sh
python -m pip install pytest
python -m pytest -q
```

Браузерная проверка требует запущенного Streamlit по адресу
`http://127.0.0.1:8501`, Playwright и Chromium:

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/frontend-audio.cjs
```

`TEST_URL` меняет адрес сервера, `CHROME_PATH` задаёт путь к установленному
Chromium/Chrome. Проверка не обращается к Gemini: она тестирует настоящий
Streamlit-канал для загрузки и отдельно имитирует ответы AI для проверки
повторных нажатий, отмены и привязки результатов к записи.

Проверено: декодирование сгенерированных WAV, MP3, M4A, AAC, OGG, OPUS, WebM
и FLAC; повтор загрузки; сохранение заметок; запись/пауза/продолжение;
скачивание без AI; узкий экран 360 px в настольном Chrome.
Нативные окна выбора файлов на iOS/Android, многочасовая запись микрофоном
и реальный вызов Gemini требуют отдельной проверки на целевых устройствах.

## Учебный блокнот

Интерфейс организован вокруг одной лекции: компактная панель аудио, личный
документ, материалы и отдельный итоговый конспект. Предметы и история хранятся
на устройстве. Название можно оставить пустым; длинное название переносится.
На широком экране «Две панели» открывает материалы рядом с заметками.
Разделитель можно перетаскивать или менять стрелками с клавиатуры.

Редактор поддерживает заголовки, списки, чек-листы, маркер, ссылки, изображения,
цитаты и стандартную отмену текстового редактирования. Ctrl/Cmd+B, I и K —
форматирование и ссылка, Ctrl/Cmd+S — сохранение. Индикатор подтверждает
завершённую запись в IndexedDB; ошибка сохранения видна отдельно.
Резервная копия включает последние изменения открытого документа даже при
ошибке локального сохранения. После подготовки копии нажмите отдельную ссылку
«Скачать резервную копию».

Рисунки сохраняются как редактируемые штрихи в координатах страницы 1000×650.
Режим «Перемещать» выбирает и переносит один штрих, «Прокрутка» не рисует.
После первого касания стилусом рисование пальцем отключается; его можно
включить вручную. Давление используется, когда браузер сообщает его.
Отмена/повтор рисунка доступны в текущем сеансе редактирования; история
отмены не сохраняется после закрытия холста. Защита от ладони зависит от
устройства и браузера.

AI-фрагмент можно вставить после выбранного блока или в конец личных заметок.
Источник сохраняется подписью, текст становится редактируемым. Итоговый
черновик показывается отдельно вместе с рисунками и ссылками на аудио из
связанных исходных блоков. Принятие черновика сохраняет предыдущий итоговый
вариант для восстановления и не меняет оригинал. Повторный анализ лекции
не заменяет отредактированный итоговый конспект. AI не распознаёт рисунки.

Дополнительная браузерная проверка:

```sh
node tests/frontend-notebook.cjs
```

Она проверяет форматирование после перезагрузки, чек-листы, рисунок и его
перемещение/отмену, вставку AI-фрагментов, предварительный просмотр и возврат
итогового конспекта, ошибки сохранения/микрофона/AI, клавиатурную навигацию
и ширины 360, 820 и 1440 px. AI-ответы в этом тесте — явные тестовые данные,
в приложение они не добавляются. `ARTIFACT_DIR` задаёт папку снимков экрана.
Уменьшенная высота окна проверяет вёрстку; настоящая экранная клавиатура,
давление стилуса и нативные мобильные жесты требуют проверки на устройстве.


## Бело-жёлтое учебное пространство

Добавлены главная, библиотека, страницы тетради, источники, чат с цитатами,
студия, карточки, планер, история и корзина. Новые разделы преимущественно
на русском. Есть светлая/тёмная тема, отдельный цвет бумаги, размер текста,
режим фокуса, мобильная навигация и поиск по тексту в Web Worker.

TXT/MD читаются локально; PDF/DOCX/PPTX передаются серверу Streamlit для
извлечения текста (до 10 МиБ, 60 страниц/слайдов, 200 000 знаков).
PDF-сканы требуют OCR, который пока не подключён. DOCX/PPTX показываются
как извлечённый текст, без обещания сохранения исходной вёрстки.
Для вопроса в Gemini передаются выбранные источники: до 20 источников и
100 000 знаков. Сервер проверяет точное присутствие цитат на указанных
страницах; это не гарантирует правильность выводов AI. Ключ хранится
только на сервере. Переход по цитате открывает использованную версию текста.

Данные хранятся в IndexedDB конкретного браузера. Аккаунты, облачная
синхронизация, совместный доступ, сообщество и дополнительные генераторы
не подключены; интерфейс объясняет ограничения. Открытое приложение
позволяет работать с локальными заметками, но холодный запуск требует сети.
