# LECTRA — система интерфейса

Реализованный интерфейс: `frontend/product.css`, `product.js`, `notebook-ui.js` и существующий редактор `app.js`. Это расширение текущего Streamlit-приложения, без смены платформы и серверного ключа.

## Навигация

Главная → Библиотека → Тетрадь: Обзор / Заметки / Источники / Чат / Студия.
Отдельные разделы: Учёба (колоды → повторение), Планер (день / неделя / месяц / список), Сообщество (состояние недоступности сервиса).
Служебные: Настройки, уведомления, помощь, корзина. Поиск и команды доступны из верхней панели, Ctrl/Cmd+Shift+F и Ctrl/Cmd+Shift+P.

На ноутбуке — боковое меню и рабочая область. На планшете — убираемая навигация. На телефоне — нижнее меню, скрываемое при вводе и открытом диалоге. В тетради сохраняется отдельная навигация по страницам. Переключение разделов не уничтожает активный аудиорекордер.

## Компоненты и состояния

- Кнопки: primary с тёмной надписью на жёлтом, secondary, quiet, icon; hover, focus-visible, disabled. Статусы обозначены текстом, а не одним цветом.
- Карточка тетради: папка, название, текстовый фрагмент, дата, меню. Массовый выбор только в библиотеке.
- Поля: подписи, обязательность и нативная валидация; длинные названия переносятся.
- Вкладки тетради: выбранная вкладка и клавиатурные стрелки / Home / End.
- Диалог: общий контейнер, закрытие, ограниченная высота, прокрутка содержимого; позиционирование учитывает Streamlit iframe.
- Источник: загрузка, готов, ошибка с повтором, требуется OCR. Выбор для AI отделён от массового выбора тетрадей.
- Сообщение: ожидание, ответ, ошибка, цитаты, остановка ожидания. Остановка ожидания не отменяет уже отправленный серверный запрос.
- Редактор: текстовые блоки, список, чек-лист, маркер, рисунок, подпись источника, история и корзина.
- Пустое состояние: объяснение и доступный следующий шаг. Неподключённые сервисы имеют отдельное объяснение.

Анимации короткие; `prefers-reduced-motion` отключает их. Нижняя панель учитывает safe-area. Проверка физических клавиатур, экранных дикторов, стилусов и нативной мобильной клавиатуры остаётся отдельным этапом QA.

## Рабочие сценарии

1. Создать тетрадь → записать мысли → добавить страницу / рисунок → сохранить → восстановить страницу из корзины.
2. Записать или загрузить аудио → прослушать / скачать оригинал → обработать с Gemini → вставить результат в заметки → собрать и принять итоговый черновик.
3. Добавить текст / документ → открыть страницу → выделить цитату → добавить в заметки / карточку.
4. Выбрать источники → задать вопрос → открыть проверенную цитату → сохранить ответ в заметки → повторить карточку.
5. Создать задачу → выбрать срок и тетрадь → отметить выполненной.

Состояния и ограничения каждого экрана перечислены в `screen-inventory.md`. Это работающий локальный этап продукта, а не обещание готового облачного сервиса.
