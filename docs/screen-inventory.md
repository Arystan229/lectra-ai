# Реестр экранов и готовности

Срез: 16 октября 2026. «Работает» означает реализованный локальный сценарий; AI-сценарии требуют действующего Gemini API-ключа. «Частично» — существенные функции из полного задания ещё отсутствуют. Неподключённые функции явно объясняют своё состояние.

| Область / экран | Состояние | Реализация и остаток |
|---|---|---|
| Первый запуск | Частично | Локальная тетрадь, пустые состояния, помощь; отдельного onboarding с аккаунтом нет |
| Главная | Работает | Последние тетради, задачи, число карточек к повторению; данные реальные |
| Глобальная навигация | Работает | Боковая панель, мобильная нижняя панель, поиск, команды |
| Библиотека | Частично | Сетка/список, поиск названия, сортировка, избранное, архив, массовые действия, 24 элемента на страницу; нет drag-and-drop с undo |
| Папки | Частично | Создание предметов, назначение и перемещение тетради через меню; нет вложенного дерева |
| Поиск | Частично | Текст страниц, источники и расшифровки; фрагмент и переход к месту; до 50 совпадений; нет фильтров и OCR рукописи |
| Обзор тетради | Работает | Описание, теги, страницы, материалы, задачи |
| Страницы заметок | Работает | Создание, переключение, переименование, корзина, восстановление |
| Текстовый редактор | Частично | Форматирование, чек-листы, изображения, цитаты, фокус, размер текста; не полноценный Word с пагинацией |
| Рисование | Частично | Ручка, маркер, ластик, перенос штриха, отмена, стилус; нет лассо групп, фигур, распознавания рукописи |
| Аудио | Работает | Запись/пауза/продолжение, загрузка, прослушивание, скачать оригинал, отметки времени, видимые стадии обработки |
| Итоговый конспект | Работает | Предпросмотр AI-черновика, принятие, предыдущий вариант, сохранение личных рисунков и источников |
| Список источников | Работает | Текст, ссылка с вставленным текстом, локальные документы, состояния файлов, выбор для AI |
| PDF | Частично | Оригинал через браузерный просмотрщик, извлечённый текст по страницам, текстовые выделения; нет OCR и аннотаций поверх координат PDF |
| Word / PowerPoint | Частично | Извлечение текста DOCX / PPTX; оригинал скачивается, исходная вёрстка не редактируется |
| Импорт из облака / веб-поиск | Не подключено | Чёткое объяснение; ссылка сама не скачивает сайт |
| Чат по источникам | Работает с API | Выбранные источники, точные проверенные цитаты, сохранение ответа, карточка, повтор после ошибки, история |
| Расширенный чат | Частично | Остановка локального ожидания; нет серверной отмены, голосового режима, внешнего веб-поиска, полноценного рендера формул |
| Студия | Частично | Доступные действия и явные ограничения для каждого типа результата |
| Конспект / отчёт | Работает с API | Генерация по источникам, текстовый просмотр и экспорт, вставка в заметки |
| Карта | Частично | Навигационное дерево источников; не семантическая AI-карта |
| Таблица | Частично | Таблица определений лекции; нет произвольного табличного редактора |
| Презентация | Частично | Просмотр содержания и существующий PPTX-экспорт лекции; нет визуального редактора слайдов |
| Инфографика / аудио / видео из студии | Не подключено | Объяснение отсутствующего генератора, без фиктивного результата |
| Учёба / колоды | Работает | Ручные карточки, карточки из ответа и определений, редактирование |
| Повторение | Работает | Открытие ответа, оценки, сроки повторения, повтор ошибок, сохранение прогресса |
| Тест | Частично | Существующий тест по лекции; нет отдельного экзаменационного режима |
| Планер | Частично | День, 7 дней, месяц, список; задачи со сроком, приоритетом и тетрадью; нет фоновых напоминаний и внешних календарей |
| Сообщество | Не подключено | Категории и объяснение; нет вымышленных публикаций, пользователей и лайков |
| Общий доступ / комментарии | Не подключено | Локальная приватность; нет аккаунтов, сервера прав, приглашений и комментариев |
| Настройки | Частично | Тема, бумага, размер текста, плотность, левша, хранилище; новые экраны преимущественно на русском |
| Профиль / безопасность / подписка | Не подключено | Объясняющие состояния; нет фиктивной оплаты и переключателей серверных функций |
| Уведомления | Частично | Локальный журнал событий; нет push и доставки в фоне |
| История / корзина | Частично | Ручные снимки, восстановление страниц/блоков/тетрадей; нет посимвольного сравнения версий и восстановления удалённого источника в UI |
| Экспорт / резервные копии | Работает | JSON с файлами источников и аудио, восстановление, существующие форматы материалов; лимиты памяти браузера остаются |
| Offline / синхронизация | Частично | Локальные данные в IndexedDB в открытом приложении; холодный запуск требует сети, облачной синхронизации нет |
| Доступность / производительность | Частично | Клавиатурные сценарии, адаптивность, reduced-motion, worker поиска, ограниченная выдача; полный аудит WCAG и физические устройства не пройдены |

## Следующие самостоятельные этапы

1. Доработать редактор: лассо/фигуры, PDF-аннотации, виртуализация длинных страниц, поиск с фильтрами и локализация новых разделов.
2. Добавить сервер аккаунтов, ACL, синхронизацию, приглашения и комментарии; затем — сообщество и push.
3. Подключить OCR и дополнительные генераторы; отдельно измерить стоимость, лимиты и качество на длинных лекциях.

Для каждого следующего этапа нужны собственные интеграционные тесты. Реализованные экраны не означают завершения всех 31 раздела исходного задания.
