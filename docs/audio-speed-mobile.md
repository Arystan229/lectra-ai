# Аудио: скорость и телефоны — 17 октября 2026

## Изменения

- Запись длительностью до двух минут: полная расшифровка, перевод и учебные
  материалы формируются одним запросом вместо двух последовательных.
- Длинная запись: сервер возвращает готовую пятиминутную часть в интерфейс,
  затем клиент запрашивает следующую. Текст можно читать до завершения лекции.
  Остановка завершает текущую часть; повтор продолжает с сохранённого места
  в текущей серверной сессии. Закрытие сессии сервера не гарантирует её сохранение.
- Перед отправкой в Gemini WAV преобразуется в FLAC без потерь. Если сжатие
  не уменьшило размер или завершилось ошибкой, используется исходный WAV.
  Это уменьшает трафик сервер → Gemini; размер исходного файла телефон → сервер
  не изменяется. Точный выигрыш зависит от сигнала.
- Готовый результат для того же аудио и языков открывается локально без нового
  запроса. Промежуточные результаты не считаются завершёнными.
- Повтор декодирования пропускает чтение уже обработанных WAV-блоков из кеша.

## Телефоны

Рекордер выбирает поддерживаемый кодек: WebM/Opus, MP4/AAC или Ogg/Opus.
При отказе браузера принять заданный битрейт повторяет создание без этой
настройки, затем пробует настройки браузера по умолчанию. Запись использует
реальные возможности браузера, а не определение по названию телефона.

Во время записи есть переключатель удержания экрана. Wake Lock может быть
запрещён браузером, iframe-политикой или режимом экономии; UI показывает
фактическое состояние. При уходе в фон запрашивается доступный фрагмент
рекордера, при завершении аудиотрека запись финализируется. Это не обеспечивает
непрерывную запись при заблокированном экране или выгрузке страницы системой.
Для долгой лекции можно записать её системным диктофоном и загрузить файл.

Сохраняются выбор аудиофайла и запасной выбор всех файлов, локальное
прослушивание, скачивание оригинала и системная функция «Сохранить / поделиться»
там, где браузер её поддерживает. Размер полей на телефоне — не меньше 16 px.

## Проверки

30 Python-тестов прошли: реальный декодер восьми аудиоформатов, возобновление,
один AI-вызов короткого пути с фикстурой, сохранение успешных частей при ошибке,
повтор только финального конспекта, точное совпадение PCM после FLAC-декодирования,
возврат к WAV при ошибке кодировщика.

`node tests/mobile-audio.cjs`: прошли проверки MP4-fallback, параметров рекордера,
удержания/освобождения экрана, контрольного фрагмента при скрытии страницы,
прерывания аудиотрека. Это проверки API-контракта с имитациями браузера.

`node tests/frontend-audio.cjs`: прошли реальная передача в Streamlit, запись,
пауза/продолжение/завершение и скачивание в Chrome при ширине 390 px, выдача
промежуточного результата и открытие кеша без сети (AI-ответы — тестовые фикстуры).
Локальный импорт небольшого WAV до предпросмотра в этом прогоне: 93 мс.
Это не измерение распознавания речи.

Реальный Gemini, Safari на iPhone и Chrome на физическом Android в этом
прогоне не проверены. Нельзя обещать почти мгновенную полную обработку:
первый результат требует передачи исходного файла и ответа модели.
Обработка длинной лекции пока последовательная; запросы не распараллелены,
чтобы не увеличивать нагрузку на бесплатные квоты.
